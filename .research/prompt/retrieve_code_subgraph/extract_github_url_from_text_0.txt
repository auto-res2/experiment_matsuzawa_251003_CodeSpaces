DNN-MFBO uses a stacked neural network (NN) architecture where each NN models one fidelity. For fidelity m > 1, the input to the NN `xm` is `[x; fm-1(x)]`, incorporating both the original input `x` and the output from the previous fidelity `fm-1(x)`. The model `fm(x) = w_m^T φ_θ_m(xm)` treats output layer weights `wm` as random variables (standard normal prior) and other NN weights `θm` as hyper-parameters. A stochastic variational learning algorithm is developed to jointly estimate the multivariate Gaussian posterior `q(wm)` and hyper-parameters by maximizing an Evidence Lower Bound (ELBO) using the reparameterization trick. For optimization, a mutual information-based acquisition function `a(x, m) = (1/λm) I(f*, fm(x)|D)` is used to select both input locations and fidelities. The computation of this acquisition function involves approximating output posteriors `p(fm(x)|D)` as Gaussian distributions through fidelity-wise moment matching and Gauss-Hermite quadrature. The conditional entropy term is handled using a Monte-Carlo approximation for `f*` samples and further approximations of conditional distributions `p(fm(x)|fM(x) ≤ f*, D)` via moment matching and Gauss-Hermite quadrature. L-BFGS with random initialization is used to maximize the acquisition function.
