# Paper Outline
PASHA is an extension of the ASHA algorithm, inspired by the 'doubling trick'. It operates by starting with a small initial amount of resources and progressively increasing them only if the ranking of configurations in the top two rungs (rounds of promotion) has not stabilized. This allows for early stopping when configuration rankings appear stable. The algorithm incorporates a 'soft ranking' mechanism to handle noise in training, considering configurations equivalent if their performance difference is below a dynamically estimated threshold, epsilon (ϵ). This ϵ value is automatically calculated by observing pairs of configurations that repeatedly swap ranks across different resource levels, taking the N-th percentile of their performance differences. The minimum resource 'r' is a user-defined hyperparameter, which is easier to set compared to ASHA's fixed maximum resource 'R'. A maximum resource 'R' is still set in PASHA as a safety net, allowing it to default to ASHA's behavior if necessary.
