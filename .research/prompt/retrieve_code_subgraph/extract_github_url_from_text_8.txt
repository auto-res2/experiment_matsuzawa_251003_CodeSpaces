# Paper Outline
DyHPO employs a Gaussian Process (GP) surrogate model with a novel deep kernel. This deep kernel, K(θ, w), uses a neural network φ as a feature extractor. The network φ takes the hyperparameter configuration, the normalized budget, and the past learning curve (Yi,j-1) as input. It is composed of linear layers and a one-dimensional convolutional layer followed by global max pooling. A squared exponential kernel k is used within the deep kernel. The optimal trainable parameters (θ, w) are found by maximizing the marginal likelihood using gradient descent with Adam. The acquisition function is a Multi-Fidelity Expected Improvement (EIMF), which calculates the expected improvement over the best observed value, either at the specific budget level or across all budgets. The DyHPO algorithm iteratively selects the most promising candidate configuration to train for one additional budget step, observes the result, updates its dataset, and retrains the surrogate model.
